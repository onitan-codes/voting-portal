# NANNM Chairman Election Portal

A responsive, front-end demonstration of a chairman election portal for the National Association of Nigerian Nurses and Midwives (NANNM).

## Preview

Open `nannm.html` in a current web browser. The project has no build step or external package dependencies.

## Features shown

- A multi-step ballot interface: email entry, a verification-code screen, candidate selection, vote review, and a completion screen.
- Responsive layout for smaller screens.
- The NANNM logo, included as `NANNM.jpg`.

## Important limitations

This repository contains a static browser demo only. It is **not an election system**:

- Email addresses are not checked against an approved voter list.
- The verification-code screen accepts any value with at least four characters; no code is sent or verified.
- Votes are not transmitted, saved, counted, or protected against repeat submissions.
- The candidate names in the page are demonstration content.

Do not use this page to run an election, and do not enter real work emails, verification codes, or other personal information.
